# OpenLyricsClient
<img src="https://badgen.net/badge/discontinued/broken/red?icon=github" />
OpenLyricsClient was the ultimate lyrics tool for singing enthusiasts. <br>
With OpenLyricsClient, you never missed a beat - it retrieved lyrics for almost any song with ease.

# Official discontinued
Sorry for those who had hopes regarding this project. Things have shifted and it's time to work for my future. <br>
It was a lot of fun working on this project from 2022 to 2025, and it helped me become a better software engineer. <br>
While working on new side projects the focus has shifted and I told myself to work further on this but it rarely happened. <br>
At some point I felt guilty for not working on it but even that feeling faded. <br>

#### Some parts of the codebase could be recycled in the future. <br>The codebase has many architectural and performance issues but feel free to learn from it!<br>
I also removed the license to make sure everyone can build their next passion project. <3
